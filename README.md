# OPD-Patient-Page
A responsive patient registration page for a hospital outpatient
department, built while learning front-end development.

## Features

- Responsive layout — works on phone, tablet and desktop
- Registration form with field-by-field validation
- Format checking for Pakistani CNIC and mobile numbers
- Department summary cards with waiting counts
- Accessible patient list table

## Built with

HTML, CSS, Bootstrap 5, JavaScript
